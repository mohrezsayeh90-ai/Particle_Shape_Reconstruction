2. PHYSICS, COORDINATES, AND EVALUATION CONTRACT

Use the same rectangular channel and frozen flow model. All lengths, times, and velocities below are nondimensional.
- L*=2.2, H*=0.30, Re=10, d_p*=0.025, rho_p/rho_f=1000.
- x*=x/L_0, y*=y/L_0, t*=t U_0/L_0, and velocity divided by U_0.
- Keep the existing Schiller–Naumann drag law and one-way coupling.
- Use the existing launch gap 1e-5 and the existing side-specific velocity bounds. The bottom launch has v_y*>0 and the top launch has v_y*<0. The shared axial bound is [-0.40, 1.50].
- Preserve the original source bounds and stopping events. Wall contact or axial boundary exit before the target time invalidates that trial.
- Baseline duration bound: 5.0 in the Dense Duck family. Use [0.03,5.0] for new matched comparisons, including the free-release comparator, to make duration bounds identical. Keep historical duration bounds when reproducing archived cases. Record the lower-bound harmonization in the run metadata. Treat a changed duration bound as a separate experiment.
- T*=max_i a_i*+0.25 and t_rel,i*=T*-a_i*. Here a_i* means duration from release to the target time.
- Preserve d_accept*=0.026 and d_search*=0.0263. Target generation may use a larger design pitch. It does not alter the trajectory acceptance thresholds.

Replay the same final candidate twice, once with the frozen PINN and once with an independently implemented planar Poiseuille carrier and DOP853, as in tools/replay.py. Verify stored checkpoint bytes and record their SHA256. Match reference and PINN release locations, times, velocities, targets, and assignments exactly. Use no training or per-case adjustment of the checkpoint. Report the independent replay as numerical verification within this model.

An accepted nominal case must satisfy all five conditions:
1. All particles exist at T* and finish both replays without an invalid boundary event.
2. Max Euclidean target error of frozen-PINN replay <= 0.003.
3. Max Euclidean target error of the independent reference <= 0.004.
4. Max endpoint difference between PINN and reference <= 0.004.
5. Minimum center distance over all pairs' shared lifetimes >= 0.026 in both replays.

Define d_min(t*) from particles already released and still present. Leave it undefined when fewer than two particles are present. Include release event times in verification. Use dense ODE output, per-pair shared-clock sampling, and local refinement of sampled minima, as in tools/replay.py. Recheck the nearest pair with finer time integration. A plotting grid does not determine acceptance. Save the minimum, its time, and pair IDs in each replay. Keep this a numerical check. Do not infer continuous collision guarantees from a sampled plot.

3. REUSE AND EXTEND THE PLANNER

Implement a reusable planner entry point. Import or extract the existing functions into an importable module with the smallest necessary changes. Do not execute entire notebook cells at import. Reuse the flow model, physics, fixed-port and free-location parameterization, candidate search, collision objective, and sparse Jacobian where possible.

A fixed port is one immovable wall coordinate and a side. A port can release repeatedly at different times. The same physical point represents one port in the entire run. In the free-location model, each particle can independently choose the side and x_launch* within the original bounds. There is no preset hardware port count in that comparator.

Replace hard-coded 6-port assumptions in the new path with an explicit list of port IDs, sides, and x* values. Decode side from the port table, not integer division by three. Retain the old six-site reproduction path. In the new port-count sweep, ports are available to the optimizer and may remain idle. Save configured and used port counts separately. If imposing a cap, enforce it during assignment and candidate changes, including swaps. Sum of per-port capacities below N is structurally infeasible. A sparse minimum-cost assignment or equivalent capacity-aware matching can initialize the discrete assignment. Endpoint distance and pairwise time-overlap clearance should both inform its refinement.

Use a bank of single-particle candidates, then discrete allocation, then joint time and launch-velocity refinement. For high N, use the existing two-stage coarse-to-direct approach and a sparse least-squares Jacobian with LSMR. Reuse cached path evaluations, integrate only changed controls, and chunk pair checks. At N=100 there are 4,950 pairs. Do not materialize a dense all-pair Jacobian or cache every possible pair of alternatives. A coarse shortlist of active pairs is acceptable during search if final verification examines every pair and missed near pairs can be fed back into refinement. Never use clamped paths or a coarse surrogate to declare acceptance.

If useful, initialize with analytical-field candidates, as in Dense Duck. Final planning and acceptance still use the frozen PINN and both independent replays. Check sparse derivatives on a small case against finite differences away from clipping and active-set transitions. Check equivalent historical fixed-port IDs on the m=3 layout. Save failures as candidate shortage, optimizer budget exhausted, solver error, invalid boundary event, clearance failure, endpoint error, target geometric infeasibility, or structural capacity infeasibility. A failed search does not establish physical impossibility.

Filled target shapes:
- Use a triangular/hexagonal lattice of pitch 0.027, with row spacing pitch*sqrt(3)/2 and alternating half-pitch shifts.
- Select centers whose disks of radius 0.0125 lie inside the target mask and inside the channel. Compute a boundary distance for polygonal masks, or use a sufficiently fine distance calculation and a documented buffer of about 0.0004. The mask is an evaluation target, not an obstacle in the ODE.
- For a count sweep, build one deterministic farthest-point ordering on the valid lattice. Start at the candidate closest to the desired center and use fixed coordinate order for ties. Use prefixes of that ordering for all requested N. Save the complete ordering. This holds mask, center and candidate lattice fixed while target density changes.
- Screen geometric capacity before planning. If the mask cannot hold the requested N at this pitch, record the request and reason. Do not silently substitute a smaller N.
- Use target centers rather than connected silhouettes to assign particles. For graphics, render particle disks with equal x*/y* scale and correct radius.

For the filled-shape benchmark, use a shared footprint W*=0.88, B*=0.23, centered at (1.52,0.15), unless a specific experiment explicitly changes the center. Let u=(x*-x_c*)/(W*/2), v=(y*-y_c*)/(B*/2).

For the center map, use a smaller stadium of W*=0.32, B*=0.11 and 18 target centers generated once about the origin. Translate the identical center pattern at each grid point. Preserve target IDs and orientation. Record the nominal center and the actual centroid of the frozen target points separately.

For the ellipse study, create 12 symmetric base centers: six at radius 0.080 with angles j*pi/3 and six at radius 0.0465 with angles j*pi/3+pi/6. Apply diag(sqrt(q),1/sqrt(q)), then rotate by theta, then translate. Here q=a/b is the requested major/minor semiaxis ratio. The area of the nominal ellipse is fixed; a=0.085 sqrt(q), b=0.085/sqrt(q). Both rings lie within the nominal ellipse as center positions. The wall constraint applies to the physical disks. At q=1 the target covariance is isotropic. Test its center response; an ellipse orientation is undefined there. This construction keeps the point count, target centroid, and intrinsic target covariance controlled. Rotating a fixed-q configuration preserves the target pair distances. Use angles measured from the downstream x* axis, with counterclockwise positive. Report angle labels in degrees and use radians internally.
