نسخهٔ آمادهٔ Kaggle/Colab، با سورس تعبیه‌شده، `Particle_Injection_PINN.ipynb` است؛

## تغییر پارامترها

دو پارامتر هندسی از فضای آموزش حذف شده‌اند:

```text
R_in  = 0.2
R_out = 0.5
عرض کانال = 0.3
```

پنج پارامتر فیزیکی قبلی `R_in, R_out, Re, d_p, rho_p/rho_f` بودند.
شش پارامتر فیزیکی جدید عبارت‌اند از:

```text
Re, d_p, rho_p/rho_f, x_p0, u_p0, v_p0
```

| پارامتر | بازهٔ پیش‌فرض | روش استفاده |
|---|---|---|
| `Re` | `0.1 … 10` | ورودی متغیر PINN سیال؛ نمونه‌برداری لگاریتمی |
| `diameter` | `0.0025 … 0.25` | قطر ذره در معادلهٔ حرکت و تشخیص برخورد |
| `density_ratio` | `100 … 10000` | نسبت چگالی ذره به سیال در معادلهٔ حرکت |
| `x_p0` | `−0.14 … +0.14` | موقعیت افقی مرکز ذره در مقطع ورودی |
| `u_p0` | `−0.5 … +0.5` | مؤلفهٔ افقی سرعت اولیهٔ ذره |
| `v_p0` | `0.25 … 1.5` | مؤلفهٔ عمودی سرعت اولیهٔ ذره |

بازه‌های سه پارامتر اول همان `0.1 … 10` برابر مقادیر پایهٔ نسخهٔ پارامتری‌اند.
بازه‌های سه پارامتر جدید، پیش‌فرض انتخاب‌شده برای شروع هستند و در سلول تنظیمات
نوت‌بوک قابل تغییرند. تمام اعداد **بی‌بعد** هستند؛ سرعت‌ها بر `U0` و طول‌ها بر
`L0` تقسیم شده‌اند و زمان با `L0/U0` مقیاس می‌شود.

در ابتدای این کانال S، جهت سیال `+y` است و عرض ورودی در راستای `x` قرار دارد.
شرایط اولیه دقیقاً چنین اعمال می‌شوند:

```text
x_p(0) = x_p0       y_p(0) = 0
u_p(0) = u_p0       v_p(0) = v_p0
```

پس `u_p0` سرعت افقی و `v_p0` سرعت عمودی است. سرعت اولیهٔ ذره با سرعت سیال
جایگزین نمی‌شود. ورودی جلو و عقبِ کانال جابه‌جا نشده‌اند.
موقعیت عرضی هر ذره باید شرط `abs(x_p0) + d_p/2 < 0.15` را داشته باشد.
در نمونه‌برداری، ابتدا قطر تعیین می‌شود و سپس موقعیت از بخش مجاز بازهٔ عرضی
نمونه‌برداری می‌شود؛ بنابراین دامنهٔ مجاز، حاصل‌ضرب کامل شش بازه نیست.

## معماری و حل یک‌طرفه

«شش پارامتر فیزیکی» با «تعداد نورون‌های ورودی شبکهٔ سیال» متفاوت است.
شبکهٔ جریان قبلی پنج ورودی `x,y,R_in,R_out,Re` داشت. شبکهٔ جریان جدید واقعاً
سه ورودی `x,y,Re` دارد؛ لایهٔ اول `Linear(3,128)` است. شعاع‌ها داخل شبکه
نمونه‌برداری یا تغییر داده نمی‌شوند. پیش‌فرض عمق و عرض همان ۶ لایهٔ ۱۲۸تایی است.

در نسخهٔ پارامتری مخزن، حرکت ذره با حل عددی ODE محاسبه می‌شد. در این نسخه نیز
قطر، چگالی و سه پارامتر اولیه به همین حل لاگرانژی داده می‌شوند. شبکهٔ مستقلی
برای تقریب مسیر ذره ساخته نشده و شرایط اولیه در آموزش PINN سیال شرکت ندارند.
این ساختار، استقلال دقیق میدان سیال از ذره و کوپل یک‌طرفه را حفظ می‌کند.
بعد از آموزش میدان، برای تغییر موقعیت یا دو سرعت اولیه، آموزش دوباره لازم نیست.

معادلات حرکت، همان درگ Schiller–Naumann نسخهٔ پارامتری با حد استوکس هستند:

```text
dx_p/dt = u_p
dy_p/dt = v_p
dV_p/dt = 18 f(Re_p) (V_f - V_p) / (density_ratio * Re * d_p^2)
Re_p = Re * d_p * |V_f - V_p|
```

گرانش، لیفت، برخورد بین ذرات، اثر دیواره بر درگ و بازخورد ذره به سیال اضافه
نشده‌اند. برخورد با دیواره با درنظرگرفتن شعاع ذره، خروج از کانال و خروج معکوس
از ورودی رویداد پایانی هستند. CSV مسیر تا لحظهٔ برخورد ثبت می‌شود و سرعت
نهایی ثبت‌شده، سرعت درست پیش از برخورد است.

## اجرا

برای Kaggle، فایل `Particle_Injection_PINN.ipynb` را Import کنید، GPU و برای
نصب وابستگی‌ها Internet را فعال کنید و Run All بزنید. تنظیمات پیش‌فرض، سقف
۶ ساعت آموزش یا ۶۰٬۰۰۰ گام، هرکدام زودتر برسد، دارند. زمان خروجی‌گیری و FEM
بعد از این بودجه است. آموزش از ابتدا شروع می‌شود؛ وزن‌های پنج‌ورودی قبلی با
این معماری سازگار نیستند.

برای اجرای محلی، فایل ZIP سورس را استخراج کنید:

```bash
python -m pip install -r requirements.txt
python run_injection_pinn.py --out results/injection_01 --device cuda --hours 6
```

برای تغییر بازه‌ها:

```bash
python run_injection_pinn.py --out results/injection_02 --device cuda --hours 6 \
  --x-p0-range -0.10 0.10 --u-p0-range -0.2 0.2 --v-p0-range 0 1.2
```

برای ادامهٔ همان آموزش، تنظیمات معماری، بازه‌ها، seed، samples، steps و وزن
continuity باید مانند اجرای قبلی باشند؛ پوشهٔ خروجی تازه انتخاب کنید:

```bash
python run_injection_pinn.py --out results/injection_continued --device cuda --hours 6 \
  --resume results/injection_01/checkpoint.pt
```

بهترین وزن با residual ثابتِ مستقل از نمونه‌های آموزش انتخاب می‌شود. دادهٔ FEM
داخل آموزش یا انتخاب وزن نمی‌آید. `checkpoint.pt` وضعیت قابل ادامه و
`best_model.pt` وزن انتخاب‌شده است. سقف زمان به‌تنهایی نشان‌دهندهٔ همگرایی نیست.

## مسیر دلخواه پس از آموزش

```python
from particle_pinn.injection import InjectionCase, load_injection_model, trace_injection

model, config = load_injection_model("results/injection_01/best_model.pt")
case = InjectionCase(re=1, diameter=0.025, density_ratio=1000,
                     x_p0=0.05, u_p0=-0.1, v_p0=0.7)
track = trace_injection(lambda xy: model.evaluate(xy, case), case, tmax=10)
print(track["outcome"])
# track['state'] columns: x, y, u_p, v_p
```

در محدودهٔ رینولدز آموزش‌دیده استفاده کنید. قطرها و سرعت‌ها باید با فرض‌های
مدل ذره سازگار باشند؛ حذف شعاع‌ها یا افزودن شرایط اولیه، اعتبار فیزیکی درگ
کرهٔ منزوی را در نزدیکی دیواره یا برای ذرات بزرگ اثبات نمی‌کند.

- `injection_summary.png/pdf`: میدان در سه رینولدز روی **همان هندسهٔ ثابت** و
  سه sweep جداگانهٔ موقعیت، سرعت افقی و سرعت عمودی اولیه.

- `trajectory_summary.json` و CSV متناظر: شش پارامتر هر مسیر، سرنوشت و `max_particle_re`.
- `best_model.pt`, `checkpoint.pt`, `training_loss.png`, `fixed_validation.json`.
- `validation.json`: مقایسهٔ مستقل با FEM در سه رینولدز؛ این مقایسه تک‌شبکه‌ای
  است و جای مطالعهٔ استقلال از شبکه یا اعتبارسنجی تجربی را نمی‌گیرد.
- `config.json`, `run_complete.json`, `failures.json`: تنظیمات، پایان اجرا و خطاهای احتمالی.
