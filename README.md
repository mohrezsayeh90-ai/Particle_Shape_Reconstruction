# Particle Shape Reconstruction

این مخزن، کد، شبکه‌های موجود، داده‌ها و نتایج بررسی‌شدهٔ کنترل رهاسازی ذرات و حرکت آن‌ها در کانال را نگه می‌دارد. منبع نوت‌بوک‌ها حساب Kaggle کاربر `mohrezsayeh` است. بررسی در ۱۰ نوامبر ۲۰۲۶ انجام شده است.

**پیشنهاد برای ادامهٔ تشکیل شکل:** `master3-clean-revised-version` به‌عنوان پایه و `dense-duck-formation-20261104-211d7de258` به‌عنوان بنچمارک متراکم. چهار حالت اردک با ۲۰، ۲۸، ۴۲ و ۶۴ ذره با وزن ثابت و حل مستقل دوباره محاسبه شدند و معیارهای عددی خود مدل را پاس کردند.

**کنترل مغناطیسی خانواده‌ای جداست:** Master9 کنترل‌کنندهٔ تک‌ذره‌ای با شرایط اولیه و خواص سیال متغیر است؛ Master10 تابع میدان را به حرکت ذره نگاشت می‌کند. این دو جایگزین برنامه‌ریز رهاسازی چندذره‌ای نیستند.

## بازتولید بدون Kaggle و بدون آموزش مجدد

Python 3.12 و CPU برای بررسی حاضر استفاده شده‌اند. محیط هر task مستقل است؛ از checkout موجود استفاده کنید و برای این کار Git worktree تازه نسازید.

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
python tools/replay.py
python tools/revalidate_magnetic.py master9
python tools/revalidate_magnetic.py master10-magnetic-function-deeponet
```

`replay.py` سلول‌های نوت‌بوک را اجرا نمی‌کند: دادهٔ ذخیره‌شده را به‌عنوان داده استخراج می‌کند، وزن‌ها را با `weights_only=True` می‌خواند و معادلات مستند را جدا بازپیاده‌سازی می‌کند. مسیرهای مرجع با DOP853 و مسیرهای شبکه با RK45 محاسبه می‌شوند. فاصلهٔ جفت‌ها روی ساعت مشترک، برخورد دیواره، دامنهٔ ورودی، زمان هدف و حساسیت عددی نیز بررسی می‌شوند. اجرای مجدد این ابزار نتایج مشتق‌شدهٔ `verification/` را به‌روز می‌کند؛ `evidence/` آرشیو باقی می‌ماند.

تأیید این آزمون‌ها به معنی تأیید آزمایشگاهی، کوپل دوطرفهٔ عمومی، مدل حباب واقعی یا تضمین همهٔ شرایط ممکن نیست. شکل اردک یک تصویر در یک لحظهٔ هدف است؛ حفظ شکل بعد از آن مدل نشده است. حالت پُرِ اردک بازسازی هندسی مرزهاست و با سطح اشغال‌شدهٔ واقعی دیسک‌ها فرق دارد.

## ثبت صحیح ران‌های بعدی

```sh
python -m pip install -r requirements-kaggle.txt
# توکن را از Secrets محیط با نام KAGGLE_API_TOKEN دریافت کنید؛ در فایل یا git ننویسید.
python tools/snapshot_kaggle.py
# برای آرشیو فایل‌های اصلی خروجی نیز، پس از فعال‌کردن دسترسی CDN:
python tools/snapshot_kaggle.py --ref mohrezsayeh/dense-duck-formation-20261104-211d7de258 --download-outputs
```

دسترسی شبکه به `www.kaggle.com`، `api.kaggle.com` و برای فایل خروجی به `www.kaggleusercontent.com` لازم است. توکن فقط به مقصدهای API کگل محدود شود؛ برای CDN عمومی توکن اضافه نکنید. این ابزار فقط می‌خواند؛ هیچ notebook یا run تازه‌ای ایجاد یا اجرا نمی‌کند.

API فهرست نوت‌بوک‌ها در این بررسی شمارهٔ نسخهٔ صفر/نامشخص برگرداند. ابزار در صورت دریافت شمارهٔ معتبر، درخواست‌ها را به همان نسخه مقید می‌کند؛ در غیر این صورت `version_pinned=false` را صریح ثبت می‌کند و زمان دریافت و SHA-256 محتوا را نگه می‌دارد. متادیتای `COMPLETE` فقط پایان اجرا را نشان می‌دهد؛ برای پذیرش عددی به آزمون‌ها نیاز است.

API در شش ران، **۳۴۷ فایل خروجی اصلی** فهرست کرده است؛ دریافت آن فایل‌ها هنوز به مجازشدن `www.kaggleusercontent.com` نیاز دارد. برای هفت نوت‌بوک دیگر، فهرست session با 404 در دسترس نیست. این کمبودها در `ARCHIVE_STATUS.json` صریح ثبت شده‌اند. منبع همهٔ سیزده notebook، وزن‌های تعبیه‌شدهٔ موجود، خروجی‌های همراه فایل و نتایج بازتولیدشده ذخیره شده‌اند؛ این مجموعه هنوز آرشیو کامل تمام فایل‌های اصلی Kaggle نیست.

## منشأ و انتشار

انتساب‌های موجود در فایل‌های اصلی حفظ شده‌اند و مجوز جدیدی برای کدهای قبلی انتخاب نشده است. برخی snapshotهای این مجموعه از نوت‌بوک‌های خصوصی دریافت شده‌اند و طبق درخواست کاربر به مخزن انتخاب‌شده منتقل می‌شوند. هیچ کلید API، مقدار Secret یا URL موقت دانلود نباید وارد Git شود. پیش از push، فهرست فایل‌ها و `SHA256SUMS.json` را بررسی کنید.
